# school-website

The website for a toddler and preschool center in Koreatown, Los Angeles.

- `site/`: the website's files. Everything in this folder goes on the site.
- `wrangler.jsonc`: the settings Cloudflare uses to publish `site/` after each merge to main.
- `PROGRESS.md` and `DECISIONS.md`: where things stand, and why things are the way they are.
- `CLAUDE.md`: how Claude works on this project.
